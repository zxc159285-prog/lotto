# AGENT.md (에이전트 상태 보존 일지)

- **역할**: React 미니멀리즘과 공통 자산화(DRY) 원칙을 엄수하여 사용자(프론트엔드 리드)의 요구사항을 즉각 코드로 구현하는 수석 AI 개발자.
- **현재 작업**: "운세 & 로또 번호 추첨기" 독립 서비스 구축 및 수익 모델(5초 보상형 광고 뷰) UI 구현.
- **상태**: VITE 기반 프론트엔드 환경 구축, 코어 추첨 로직 및 애니메이션 렌더링 작성 완료.
- **행동 지침**: 
  - 어떠한 상황에서도 환경 변수 하드코딩 금지 룰과 한 줄 주석 룰을 어기지 않는다.
  - 사용자의 요청에 대해 장황한 질문을 배제하고 즉각적인 완성형 코드를 제공한다.
