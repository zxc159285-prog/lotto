# 프로젝트 코드 컨벤션 및 개발 원칙

1. **미니멀리즘 (CRITICAL)**
   - 가독성을 최우선으로 하여 불필요한 데코레이션, 빈 줄을 배제한다.
   - `useState`는 최소화하며, 고정 데이터나 파생 변수는 렌더링 블록 내 `const`로 캐싱한다.
   - 불필요한 제어 컴포넌트는 피하고 폼 데이터는 가급적 `useRef` 등으로 비제어로 처리한다.

2. **DRY 및 공통 자산화 (CRITICAL)**
   - 반복되는 UI요소(예: 로또 공 렌더링, 페이징 버튼바 등)는 즉각 전역 컴포넌트로 분리하여 재사용한다.

3. **한 줄 한글 주석 의무화 (CRITICAL)**
   - 모든 단위 메서드, 상태값, 이벤트 핸들러 위에 한 문장으로 간단한 한 줄 주석을 의무적으로 작성한다.
   - 장황한 JSDoc 방식은 금지한다.

4. **환경변수 하드코딩 금지 (CRITICAL)**
   - 앱 내 모든 상수 및 외부 경로는 반드시 루트 `.env`에 정의하고 `import.meta.env`로 참조한다.
