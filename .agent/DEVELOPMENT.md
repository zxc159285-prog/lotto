# 기능별 작업 과정 기록

## 1. 초기 환경 및 코어 로직 구축 (완료)
- 운세 컨셉에서 '의미 있는 숫자 기반 하이브리드 로또'로 기획 피벗 후 로직 리팩토링.
- `fortuneUtils.js`에서 슬라이딩 윈도우 방식으로 사용자의 긴 숫자를 분할하고, 10단위 밴드(Band) 균형을 맞추는 로직 적용.

## 2. 수익 모델(쿠팡 파트너스) 연동 (완료)
- `App.jsx` 내 5초 모달창과 메인 폼, 결과창 상단에 배너를 배치함.
- React의 VDOM과 외부 스크립트 충돌 방지를 위해 `public` 내에 `coupang.html`, `coupang-banner.html`을 분리하고 `iframe`으로 호출하는 가장 안전하고 독립적인 아키텍처를 채택함.

## 3. 배포 및 검색 엔진 최적화 (SEO) (완료)
- 깃허브 시크릿 유출 방지를 위해 `.gitignore`에 `.env` 추가 후 깃 캐시 삭제.
- Vercel CLI(`npx vercel --prod`)를 통해 프로덕션 서버에 성공적으로 다이렉트 배포함.
- `index.html`에 구글 서치콘솔 및 애드센스 소유권 인증 태그 삽입 완료.
- 유기적 트래픽 유입 및 카카오톡 공유 클릭률을 높이기 위한 타이틀, 메타(description, keywords), 오픈그래프(og) 태그 코딩을 완벽하게 적용함.
