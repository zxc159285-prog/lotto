# 기능별 작업 과정 기록

## 1. 초기 환경 구축 (완료)
- Vite + React 기반으로 `fortune` 워크스페이스에 프론트엔드 환경을 구축 완료함.
- 프로젝트 룰에 따라 `.agent` 디렉토리를 생성하여 규칙에 따른 문서화 구조를 확립함.
- 환경변수 관리를 위해 루트에 `.env` 파일을 생성하고 하드코딩을 제거함.

## 2. 운세 및 로또 기능 코어 개발 (완료)
- `fortuneUtils.js` 유틸리티를 분리하여 운세 멘트 랜덤 반환 시스템과 `Math.random()` 기반의 빠르고 중복 없는 6자리 난수 추첨 기능을 완벽히 분리 구현함.
- `App.jsx`에서 `useRef`를 활용해 생년월일 입력을 비제어로 처리하여 불필요한 리렌더링을 방지함 (미니멀리즘 준수).
- `LottoBall.jsx` 공용 컴포넌트를 생성하여 로또 공 렌더링 시 코드를 재사용함 (DRY 준수).
- `index.css`를 통해 딜레이가 적용된 팝인(Pop-in) CSS 애니메이션을 구현하여 시각적 몰입감을 극대화함.

## 3. 수익 모델 (보상형 광고) 연동 (완료)
- 리워드 광고 모델을 가정한 5초 지연 콜백 모달창을 `App.jsx`에 구현함.
- 광고 시청 버튼 클릭 시 모달이 나타나며 남은 시간을 초 단위로 렌더링하고, 완료 시 보너스 로또 번호 6자리가 추가로 화면에 렌더링되도록 처리함.
